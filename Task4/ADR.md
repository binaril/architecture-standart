Функционал выгрузки файла ставок в облако было решено реализовать в отдельном микросервисе с взаимодействием через очередь kafka
- для изоляции взаимодействия с облаком
- снизить необходимость внесения изменений в основной функционал
- возможность горизонтального масштабирования основного сервиса без сервиса интеграции

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Опишите здесь наиболее важные альтернативные решения.
- В рамках MVP можно было реализовать интеграцию с облачным сервисом в микросервисе DepositAPI, с ограничениями по масштабированию и рисками по внесению изменений
- В дальнейшем, при согласовании с партнерским кол-центром можно перейти на другие способы информирования менеджеров о доступных продуктах, например через отдельный раздел на сайте
- В качестве альтернативы облачному сервису можно использовать собственный S3 сервис

**Недостатки, ограничения, риски**
