Сайт
В MVP новый функционал интегрирован с интернет-банком для снижения затрат на разработку и поддержки единого стиля. В дальнейшем возможно выделение отдельного микрофронтенда для сайта.

Интернет-банк
Так как в качестве системы интернет банка используется монолит (фронт+бакенд) то было принято решения переходить на микросервисную архитектуру путем интеграции микрофронтендов на стороне клиента, как наиболее доступный. Таким образом в систему интернет-банка добавляется микросервис предоставления данных по депозитам и обработки заявок.

АБС
Так как БД уже сильно нагружена, то было решено управление заявками и депозитами реализовать в отдельных микросервисах с собственными БД. Доступ к микросервисам реализован через микросервис Gateway, к которому подключается клиент на Delphi. Для применения автоматизации, например создания депозита по заявке, был добавлен микросервис интеграции АБС, который выполняет изменения в основной БД.
Создание, изменение и обработка заявок осуществляется через очереди kafka, для обеспечения оповещения всех заинтересованых сервисов

Интернет-шлюз
Для регулирования нагрузки на телеком провайдера была добавлена очередь kafka СМС сообщений
